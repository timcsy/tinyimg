# TinyImg - 圖片壓縮工具

一個簡單易用的純前端圖片壓縮工具，可以快速將圖片壓縮到小於 1MB。

![TinyImg Logo](https://via.placeholder.com/400x200/667eea/ffffff?text=TinyImg)

## ✨ 特色功能

- 🖱️ **多種上傳方式**：支援拖曳、點擊選擇、剪貼簿貼上
- 🗜️ **智慧壓縮**：自動壓縮到指定大小，支援品質調整
- 📋 **剪貼簿整合**：一鍵複製壓縮後的圖片
- ⬇️ **快速下載**：直接下載壓縮後的圖片
- 📱 **響應式設計**：完美支援桌面和行動裝置
- 🎨 **現代化介面**：美觀的使用者界面和流暢動畫

## 🚀 快速開始

### 線上使用

直接在瀏覽器中開啟 `index.html` 檔案即可使用。

### 本地開發

1. 克隆專案到本地：
   ```bash
   git clone <your-repo-url>
   cd tinyimg
   ```

2. 使用簡易伺服器運行（可選）：
   ```bash
   # 使用 Node.js serve
   npx serve .
   
   # 或使用 Python
   python -m http.server 8000
   ```

3. 在瀏覽器中開啟 `http://localhost:8000`

## 💡 使用方法

### 上傳圖片
- **拖曳上傳**：將圖片檔案拖曳到上傳區域
- **點擊選擇**：點擊「選擇檔案」按鈕
- **剪貼簿貼上**：使用 `Ctrl+V` (Windows) 或 `Cmd+V` (Mac) 貼上圖片

### 調整設定
- **品質**：調整壓縮品質 (10%-100%)
- **目標大小**：設定目標檔案大小 (KB)
- **輸出格式**：選擇 JPEG、PNG 或 WebP 格式

### 取得結果
- **複製到剪貼簿**：點擊「複製到剪貼簿」按鈕
- **下載檔案**：點擊「下載」按鈕儲存到本地

## 🔧 核心功能

### 圖片壓縮演算法
1. **尺寸優化**：大圖片自動縮放到合適尺寸
2. **品質調整**：使用 Canvas API 進行品質壓縮
3. **漸進式壓縮**：自動調整參數直到達到目標大小
4. **格式轉換**：支援多種格式之間的轉換

### 使用者體驗
- **即時預覽**：同時顯示原始和壓縮後的圖片
- **詳細資訊**：顯示檔案大小、尺寸、壓縮率
- **進度指示**：清楚的處理進度顯示
- **通知系統**：友善的操作反饋

## 🎯 使用場景

- **網站開發**：優化網站圖片以提升載入速度
- **社群媒體**：快速壓縮圖片以符合平台限制
- **電子郵件**：減少附件大小
- **儲存優化**：節省本地和雲端儲存空間

## 🚧 已知限制

- 剪貼簿功能需要 HTTPS 或 localhost 環境
- 處理超大圖片時可能需要較長時間
- 某些舊版瀏覽器可能不支援所有功能
